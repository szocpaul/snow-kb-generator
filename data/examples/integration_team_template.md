# Knowledge Base Structure for Interface Documentation

## KBA1: Overview / Summary

**Theme:** Overview

### Purpose / Background / Overview
Provide a business-level understanding of the integration.
Act as the main entry point for all users.

### Content
- What the interface is
- Who uses it
- What type of data is exchanged
- High-level process flow
- Table of related KB articles, including:
  - Short description
  - Article number
  - Target audience

### Target Audience
- Knowledge users
- Process Owners
- Support teams
- New team members

---
